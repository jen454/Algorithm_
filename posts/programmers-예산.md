# [프로그래머스] 예산 (Python 풀이)

## 문제접근
https://school.programmers.co.kr/learn/courses/30/lessons/12982

부서별로 신청한 금액이 담긴 배열 d와 예산 budget이 주어지고, 각 부서는 신청한 금액을 정확히 지원해야 하는 상황에서 최대한 많은 부서를 지원해 줄 수 있는 개수를 구하는 문제이다.

한 부서에 지원하는 금액은 신청한 만큼 정확히 줘야 하므로, 예산 안에서 개수를 최대화하려면 금액이 작은 부서부터 지원해야 유리하다.

주석에도 최대한 많이 줘야 하니까 d 배열을 오름차순 정렬하고 앞에서부터 예산에서 빼보면 될 것 같다고 되어 있는데, 이 아이디어를 그대로 구현하면 된다.

## 풀이
**1.** d 배열을 오름차순으로 정렬해서 금액이 작은 부서부터 확인할 수 있게 한다.

**2.** 정렬된 d를 앞에서부터 순회하면서, 현재 금액이 남은 budget 이하이면 지원 가능하다고 보고 answer를 1 늘리고 budget에서 그 금액만큼 뺀다.

**3.** 금액이 budget보다 커지는 순간부터는 더 이상 지원할 수 없으므로 answer 값을 그대로 유지한 채 끝까지 순회한다.

**4.** 순회가 끝나면 지원할 수 있었던 부서의 개수인 answer를 반환한다.


## 전체코드
```python
def solution(d, budget):
    answer = 0
    d.sort()  # 금액이 작은 부서부터 지원해야 최대한 많은 부서를 지원할 수 있음

    for i in d:
        if (i <= budget):
            answer += 1
            budget -= i
    return answer
```
