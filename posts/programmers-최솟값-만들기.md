# [프로그래머스] 최솟값 만들기 (Python 풀이)

## 문제접근
https://school.programmers.co.kr/learn/courses/30/lessons/12941

길이가 같은 배열 A, B에서 각각 한 개씩 숫자를 뽑아 곱한 뒤 이를 누적해서 더하는데, 한 번 뽑은 인덱스는 다시 쓸 수 없는 상태로 배열 길이만큼 반복해서 누적값을 최소로 만드는 문제다.

즉 A와 B의 원소를 중복 없이 짝지어서 곱셈의 총합이 최소가 되는 조합을 찾아야 한다.

최소가 되는 조합을 어떻게 찾을지 고민했는데, 작은 원소를 큰 원소와 곱하는 방식이 가장 작은 조합이 될 것이라 생각했다.

**-> A 배열은 오름차순으로, B 배열은 내림차순으로 정렬한 뒤 같은 인덱스끼리 곱해서 더하면 될 것 같다.**

예시로 A = [1, 2, 4], B = [5, 4, 4]인 경우 1×5, 2×4, 4×4로 짝지어지고, A = [1, 2], B = [4, 3]인 경우 1×4, 2×3으로 짝지어지는 방식이다.


## 풀이

**1.** newA는 A를 오름차순으로 정렬한 배열, newB는 B를 내림차순으로 정렬한 배열로 만든다.

**2.** 배열 길이만큼 반복하면서 같은 인덱스의 newA[i]와 newB[i]를 곱해 answer에 누적한다.

**3.** 모든 인덱스를 순회한 뒤 answer를 반환한다.


## 전체코드
```python
def solution(A,B):
    answer = 0
    newA = sorted(A)
    newB = sorted(B, reverse=True)
    
    # 작은 원소를 큰 원소와 곱해야 총합이 최소가 되므로
    # A는 오름차순, B는 내림차순으로 정렬 후 같은 인덱스끼리 곱함
    for i in range(len(A)):
        answer += newA[i] * newB[i]
    return answer
```
